# Misaligned Templates

「对不齐」自定义模板开源库。

这里收集可以导入「对不齐」使用的自定义排版模板。每个模板都用独立文件夹保存，包含模板展示图和可直接导入的 JSON 代码，方便浏览、复用和二次创作。

## 这个仓库怎么用

### 使用已有模板

1. 打开「对不齐」：<https://misaligned.pages.dev/>
2. 点击顶部的「+」进入「自定义模板」。
3. 打开本仓库中感兴趣的模板文件夹，查看 `preview.png` 了解效果。
4. 下载或复制 `template.json` 的内容。
5. 回到「对不齐」，上传 JSON 文件，或将 JSON 内容粘贴到输入框中导入。

模板导入后只存在于当前浏览器会话中。需要长期保存时，请把 JSON 文件留在本地或重新从本仓库下载。

### 添加新模板

每个模板使用一个独立文件夹，命名格式如下：

```text
001_模板名称/
├── 001_模板名称.png
├── 001_模板名称.json
```

展示图和 JSON 文件名可以使用模板代码加模板名称，便于在仓库中直接识别；不要求统一叫 `preview.png` 或 `template.json`。

模板信息统一维护在本根 README 的模板库区域，不要求每个模板文件夹额外附带 README。

| 信息 | 说明 |
| --- | --- |
| 模板代码 | 使用三位数字，例如 `001` |
| 模板名称 | 与文件夹名称和 JSON 中的 `name` 保持一致 |
| 贡献者 / 制作者 | 写明个人名称或 GitHub 用户名 |
| 版本号 | 例如 `v1.0.0` |
| 更新日期 | 使用 `YYYY-MM-DD` 格式 |
| 展示图 | 使用 `preview.png`，展示最终排版效果 |

`template.json` 应保持为「对不齐」可识别的模板 JSON。不要把说明文字混进 JSON 文件，否则会无法导入。
